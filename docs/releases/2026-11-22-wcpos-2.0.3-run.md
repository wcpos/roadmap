## B1 — app v2.0.3 notes (GitHub release body)

> WCPOS 2.0.3 keeps the open product tile the right size when a browser or desktop window is resized, keeps a cart line's custom field in view while you type a name that starts with an underscore, and fixes the wording of the "no products match" message.
>
> Upgrade and compatibility
> - Works with every 2.0.x plugin. No plugin update is needed.
>
> Fixed
> - **In the browser and the desktop app, the product tile you open on the POS screen now resizes with the window.** The tile was re-measured on phones and tablets only, so on the web it kept its old size after a resize (#3731).
> - **A custom field on a cart line, fee or shipping line whose name starts with `_` stays on screen while you edit it.** It used to vanish as soon as it saved and could only be reached in the JSON tab. It now sits under Hidden fields like any other `_` field; only WCPOS's own keys stay out of the form (#3729).
> - **The "no products match" message reads correctly.** Category and tag names show `&` and other characters as typed instead of `&amp;`, one product says "product", and a category with no products says "Nothing matches these filters" instead of "None of the 0 products" (#3730).
> - **The hover on the order-source icon in the Orders table is a light wash again**, in line with the other icon buttons, instead of the full tint it was given by mistake (#3728).
>
> Maintenance
> - Sync tests, and release tooling for the web bundle's CDN check (#3725, #3726).
>
> Full diff: https://github.com/wcpos/monorepo/compare/v2.0.2...v2.0.3
