## Release notes (app v1.10.25) — B1, file `app-notes.md`

- **Till totals now match your store to the cent** on stores that round tax at subtotal level. With WooCommerce's "Round tax at subtotal level" setting on, a sale could come out one cent different from the store's own total (US stores with stacked state and county rates), or a fraction of a cent different in tax on tax-inclusive prices, and the checkout stopped with a totals-changed alarm. The till now rounds tax exactly the way WooCommerce does.
- **Adding a Bluetooth printer no longer crashes the app** on iPad and iPhone. The first printer scan after launch could run before Bluetooth was ready — longer still while the Bluetooth permission prompt was on screen — and the app closed. The scan now waits for the adapter; the error, if it ever recurs, is reported with a real message instead of "No error message".

- Electron #492: `.deb`/`.rpm` installs report their package format to the update feed; affected merchants install 1.10.28 by hand once.
- If 1.10.21/1.10.25 misbehaves at checkout, look at order-math and the auth-path changes first.
