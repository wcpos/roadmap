## B1 — app notes (app v1.11.9 release body; desktop body = the same lines + footer)

- **The refund window is titled with the order number, not the order's database id.** On a store where the two differ, such as one with a sequential order number plugin, the refund window named a different order than the row that opened it. (#3159)
- Translations updated to 2026.11.0. (#3156, #3175)

Plugin update 1.11.8 (free, and Pro 1.11.10) ships alongside: new sales start from WooCommerce's own "Calculate tax based on" setting, each Pro store can choose the customer's billing or shipping address there, and an extension update that needs a newer WCPOS than the site runs is no longer offered.

Desktop footer: "Desktop build of WCPOS app **1.11.9**. Available for macOS (Intel + Apple Silicon), Windows, and Linux (`.deb` / `.rpm`)."
