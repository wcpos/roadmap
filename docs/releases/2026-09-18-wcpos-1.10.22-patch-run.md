## Release notes (app v1.10.22) — B1, file `app-notes.md`

- **A web till with the POS open in more than one tab repairs its local database again.** Since the 1.10 storage repairs shipped, every repair on web was refused whenever another tab of the same store could be open, so a damaged record stayed damaged and the same storage errors repeated on every sync. The tab that leads the store now owns the repair and the other tabs follow it. Web merchants receive this through WooCommerce POS plugin 1.10.18, which serves the storage worker; desktop and phone apps carry it in this release.
- **Voiding an order the server had refused no longer fails silently.** When an order could not be created on the server (for example while the till was signed out) and the cashier then voided it, the void raised an error nothing caught and the order stayed in the cart. The till now removes the order and its failed request locally and confirms the removal; any other failure to void shows an error instead of nothing.
- **A till opened from WordPress admin no longer sends an invalid sign-in token on its first requests.** A request made before a token was stored carried the word "undefined" as its credential, which the server rejected as an invalid token instead of falling back to the WordPress login session. Such requests now carry no token, and a retry after a token refresh no longer keeps the old token in the request address.

Phone and tablet apps on the 1.10.18 store build receive this version as an over-the-air update: it downloads in the background and applies on the next cold start after that, with no store update needed. Older store versions must first update to 1.10.18 from the App Store or Google Play.

### Notes worth keeping

- **A worktree-isolated Claude session cannot run git against another repo, and the guard also refuses shell loops, `$var` paths and command substitution.** Everything cross-repo this train (electron mirror, four release branches, worker vendoring, tag, ref bumps) went through the git-data API from script files in the scratchpad; one script per step, literal paths inside. The recipe is now cheaper than a second worktree for anything that is a file copy plus a commit.
- **jsDelivr serves a new tag's `metadata.json`/`index.html` before its new entry asset.** The entry `.js` 404'd for about a minute after the tag while `x-jsd-version` already read 1.10.32; it was 200 on the next probe. Read the entry asset again before calling web red.
- **electron `next` and `main` had disjoint halves of the recovery wrapper** (#435's gate on `next`, #460's repair-retry on `main`), so the `main` mirror was built from the monorepo PR's files, not from either electron branch. Compare sha256 of both branches against the monorepo before choosing a source.
- **The Codex-drafted void fix needed the `identity-ambiguous` rule the drain and dead-letter discard already apply** (`rejectionSuggestsServerRecord`). Any spec that decides "born-local" from revision + id alone is missing the third signal; name it in the spec.
