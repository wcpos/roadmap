## B1 — app notes (app v1.11.8 release body; desktop body = the same lines + the desktop line + footer)

- **A scan after a completed sale adds one unit again, not two or three.** With "Automatically show receipt after checkout" off, every sale on 1.11.6 and 1.11.7 left a hidden copy of the POS screen behind the cart, and each copy added the scanned product; a refresh cleared it. Leaving checkout now returns to the one POS screen it was opened from. Reported on Chrome on a Mac with a barcode wedge scanner. (#3148)
- **An order set aside on a phone stays set aside while another order is paid.** With the receipt off, paying a second order could put the set-aside order back into the cart after checkout, so the next scan landed in the wrong customer's order. The cart now starts a new order after the sale. (#3150)
- **"Return to cart" after a stock rejection at checkout returns to the same open cart** instead of opening a new one. (#3148)

No plugin update ships with this release; the app works with every 1.11.x plugin.
