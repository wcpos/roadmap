# WCPOS Release Run Reference — 2026-08-07 (1.9.17 plugin-only patch)

A **plugin-only patch** of the free and Pro PHP plugins (no monorepo / web-bundle / electron /
mobile this cycle). Headline: **~2.4 MiB smaller plugin package** (free #1538) to resolve Pro
installation failures on hosts with restrictive upload/disk limits. Unlike 1.9.15/1.9.16 this
was not a single-fix release — main had accumulated 8 merged PRs since v1.9.16 (Aug 5–7), all
of which shipped.

## Release Versions

| Component | Repo | Previous | Released |
| --- | --- | ---: | ---: |
| Free WordPress plugin | `wcpos/woocommerce-pos` | `v1.9.16` | `v1.9.17` |
| Pro WordPress plugin | `wcpos/woocommerce-pos-pro` | `v1.9.16` | `v1.9.17` |

No translation bump (both stayed `2026.7.8`). Free zip: 9.5M → **7.1M**; Pro zip: **7.6M**.

## What shipped

Free (`main` since v1.9.16, all merged before this run — a *release* run, not authoring):

- **#1538 — reduce packaged plugin size** (the release trigger): template-gallery preview
  PNGs → WebP, dropped a bundled 396 KB TTF, stripped ~14k lines of unused vendor code
  (Phpfastcache et al.).
- **#1444 + #1480 — Pro licence/update-cache fixes**: clear `update_plugins` transient on
  licence change (stale licence key in cached package URLs) + write-back recursion guard.
- **#1465 — one cashier UUID per user on multisite** (plus legacy-adoption guards and
  concurrent-write coordination).
- **#1473 — orders batch API hardening**: skip malformed `meta_data` entries (PHP 8 TypeError
  → 500 mid-batch → duplicate-order risk on retry), 400 on malformed UUIDs.
- **#1464 — server-authoritative POS order audit meta** (anti-forgery; `Pos_Order_Audit`
  service) + stricter till cash validation (reject signed/scientific-notation amounts).
- **#1463 — cloud print Wave 1 consolidation**: `Provider::normalize()`/`DEFAULT_PROVIDER`,
  Star Online diagnostic moved into `Cloud_Print_Diagnostic`, `Print_Format_Resolver` as the
  single content-type authority, and `template_engines` served on the settings response
  (additive API field — the reason 1.9.17-as-patch is a slight semver stretch).
- CI-only: #1475 merge-gate fail-closed, #1484/#1520 composer-audit ignore, test matrix bumps.

Pro-side code change this cycle: **#419 — expose underlying extension install errors** (AJAX
upgrader skin; keeps the `install_failed` code/status but surfaces the real WP error) — nicely
on-theme with the install-failure headline. Rest was CI-only.
