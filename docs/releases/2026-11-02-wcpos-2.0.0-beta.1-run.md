## What the plan got wrong

- **`tag-and-release.yml` reads `.monorepo-ref` at the dispatch's `GITHUB_SHA`**, and a dispatch sent seconds after the ref-bump merge resolved the pre-merge `main`. Pass `monorepo_ref=<tag>` explicitly on a release day, or wait a minute after the merge.
- **`build.yml` has no ref input.** It builds whatever `main` is at dispatch; on a day other sessions merge, that is not the tag. `gh workflow run build.yml --ref v2.0.0-beta.1` builds the tag's tree (the workflow file exists there); write it that way in Phase 5's beta N+1.
- **Android on EAS needs the large worker now.** Every Android build since 2026-11-02 11:06 (dev clients and production alike) lost its Gradle daemon mid native build on the legacy worker; `android.resourceClass: "large"` on the production profile fixed it (monorepo#3208). The development profile, which the native E2E's dev-client builds use, still runs on the default worker and will keep failing until it moves too.
- **Sentry is a hard dependency of both native builds** (source-map upload is a Gradle/Xcode build phase); an outage fails the build after the EAS minutes are spent.
- **The 2.x docs tree is unbuilt by design** (`onlyIncludeVersions`), so a tester page there is invisible; the page lives in 1.x with eleven locales, which the completeness gate demands.
- **Three extension repos had `release.yml` push-only or dispatch-only** with no beta lane, and PayArc's `main` had to gain `workflow_dispatch` before a dispatch on `next` was accepted. Mercado Pago's `next` was six commits behind `main` and its tests had drifted from Free 2.0 (`Ledger::save()` deleted in Free `b9b9aa74`; the settings hook renamed).
- **The tester page sent Pro testers to the private Pro GitHub release**; Paul: *"The Pro users need to download the beta from https://wcpos.com/account/downloads"* (docs#568).
- **The account Downloads page dropped prereleases entirely**, so "available in the account area" needed its own entitlement branch (active licence only) and card; the bot's translations pin PR on the monorepo came from the 1.11 `main` and had to be replaced.
