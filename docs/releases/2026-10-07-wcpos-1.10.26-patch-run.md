### Notes worth keeping

- **A bump waits for nothing — and the trap this time was the previous run record.** The 1.10.25 record's "Gate handling" line ("free's merge waits for its tip's PHP Tests") was read as precedent and the free bump was held for the tip's 10-cell matrix until Paul stopped it. The checklist (C1) outranks the last run's narrative. Memory `feedback-a-version-bump-never-waits-for-tests` written; the sentence is removed from this record's Gate handling.
- **Electron has no lockfile, so a toolchain publish can break a train with zero repo changes.** `@electron/rebuild` 4.2.1 (2026-10-06 22:35 UTC) changed the `.forge-meta` rebuild marker to include the target platform, so Forge's "Preparing native dependencies" no longer trusted the step's `electron-rebuild -f -o usb` output and rebuilt `usb` itself, where the compile line carries `-std=c++1y` and `node-addon-api`'s C++17 headers fail (macOS + Linux; Windows unaffected). Pin: electron#497 (`devDependencies` + `pnpm.overrides`). Read a native-rebuild failure on an unchanged electron repo as a fresh-resolve toolchain change first: `npm view <pkg> time` for `@electron/rebuild`, `@electron/node-gyp`, `@electron-forge/*`. A proper fix is a lockfile in the electron repo, or making the smoke-test step honour the already-rebuilt `usb` — a ticket, not a train change.
- **Per-platform re-dispatch works and runs in parallel.** `tag-and-release.yml`'s concurrency group includes the platform input, so `linux`, `macos` and `macos-arm64` dispatched back to back ran at once and appended to the same draft by tag; the windows assets from the first run stayed. Tag at the tip that built the re-dispatched assets, and set the draft's `target_commitish` explicitly in the publish PATCH (it was `main`).
- **A train whose reason is an open PR arms auto-merge on it and cuts on `MERGED`.** #2151 merged 90 s after auto-merge was armed; no watcher needed.
- **`@1.10` jsDelivr needed exactly one purge again** (read 1.10.35 before, 1.10.36 after).
- **The F1 agent's conflicts were all in next-restructured files** (header `SystemBars`, refunds as an engine query); the "Not ported" line is the honest outcome when next has no mechanism. `compare/next...main` was exactly this train's commits — the 1.10.25 sync had done its job.
