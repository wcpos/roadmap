## B1 — app notes (app v1.11.10 release body; desktop body = the same lines + footer)

- **Re-opening an order from the Orders screen leaves exactly one POS screen, so each barcode scan adds one unit, not two.** Re-open pushed a second copy of the POS screen on top of the one already open, and both copies listened to the scanner; the second copy also kept the cart from clearing. The POS screen now settles to a single till whichever way it is opened, and only one screen owns the scanner at a time. Reported on the desktop app 1.11.9. (#3281)
- **Re-open refuses an order that is already paid and points at Refund.** A completed, card-paid order could be sent back through the till and charged a second time. Re-open now shows "This sale is already paid. Refund it instead of re-opening it." and changes nothing; an unpaid order re-opens as before. (#3184)
- Translations updated to 2026.11.1. (#3185)

No plugin update ships with this release; the app works with every 1.11.x plugin.

Desktop footer: "Desktop build of WCPOS app **1.11.10**. Available for macOS (Intel + Apple Silicon), Windows, and Linux (`.deb` / `.rpm`)."
