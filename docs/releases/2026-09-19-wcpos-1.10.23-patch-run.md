## Order actually used, and why it was inverted

`apps/main/public/opfs.worker.js` moved in monorepo #2180, so the spine's "free first" inverts:

**monorepo bump → bundle build → tag v1.10.33 → app release → re-vendor worker into free → free → Pro → desktop → mobile → docs.**

Publishing free ahead of the bundle tag would have shipped the *old* worker to WP.org under a changelog promising app-side fixes web merchants did not have.

## Things that cost time, or nearly did

- **`gh run watch --exit-status` exiting 0 does not mean the run passed.** Free's PHP Tests on `bcd428a0` was reported green off that exit code; its conclusion was `cancelled` — merging the release PR pushed a new main commit and the concurrency group killed it. A cancelled gate reads exactly like a passed one. **Always read `conclusion`, never the watcher's exit code.**
- **`gh release edit <tag>` without an explicit tag is the documented draft-tag reset.** Did it on electron's draft; the tag happened to survive, but that was luck. Passed `tag_name` explicitly on the publish.
- **Electron's `release-notes` mirror got the app version right this time** — the footer said "Desktop build of WCPOS app **1.10.23**" against desktop tag 1.10.26, so the job now reads the bundled app version rather than its own tag. The old wrong-version warning appears to be fixed; the mirror still never adds the desktop-only line, which was hand-added.
- **The absolute-tree guard blocks `npm ls -g` even with a `cd` prefix**, because a global list names no tree. Finding tooling that way is a dead end; look for how CI invokes it instead.

## Risk carried into production

Free 1.10.19 carries three Codex-delegated architecture refactors — `Controller_Registry` (v2 service map derived from v1, fifteen `API\V2\*` classes deleted to aliases), the `Order_Write_Payload` collapse, and `Create_Identity` — with the last review-fix landing 05:10 the same morning. Flagged before the go and shipped per the batch rule. **If 1.10.19 misbehaves, look there first, not at the storage work.**

**Resolved after the fact: the full PHPUnit matrix came back green** (run 35424082208, `conclusion: success`, all 17 jobs including all 10 PHP/WP/WC combos and Code Coverage). It was still running when free was published, so for about 50 minutes the refactors were public on unproven matrix evidence — PHPStan, Lint, Smoke Test and REST lane coverage were green, and the preceding commit's matrix had passed, which is what the go rested on. The ordering to prefer next time: free's plugin leg is the one leg whose gate is worth having in hand before publish, because it is the leg that carries a big PHP diff rather than a version bump.
