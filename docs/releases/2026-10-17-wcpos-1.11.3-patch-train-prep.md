## Risk read (per item, verified against the diffs, not the PR claims)

- **monorepo #2636 instance header — the one to watch.** Additive header on every store request; `sites` schema 6 → 7 with a no-op migration (existing documents unchanged; web keeps the header OFF until a per-site probe proves it passes). Native and desktop send it unconditionally, so a host that rejects unknown request headers would fail sync there; not seen, not evaluated live (ModSecurity CRS does not block unknown `X-` headers by default). The no-Web-Locks cross-tab consensus settles after 250 ms. **Revert is not clean**: documents already at schema 7 cannot reopen on a schema-6 build, so if it misbehaves the fix is forward. Merged 14:54 UTC today after ten Codex rounds; suites green (sync-engine 1,965, utils 347, core 2,848, main 396).
- **monorepo #2634/#2643 request deadline.** Any engine request unanswered for 60 s is abandoned and retried, logged as unreachable (status 0). A store whose legitimate requests exceed 60 s will now show unreachable rows in Logs where it previously hung the lane. Low.

- **monorepo #2590** web demo path only. **#2592** iOS field remount while unfocused only. Low.

## B1 — app notes (app 1.11.2, GitHub release body and electron footer source)

- **Couponed sales no longer come back as "different totals" on stores with tax-inclusive prices or compound tax rates.** Each discount and its tax are now rounded the way WooCommerce rounds them.
- **Sync no longer stalls silently when the store never answers a request.** A request left unanswered for a minute is given up and retried instead of holding its sync lane until the app is restarted.
- **The 1.11.1 memory fix now covers large catalogues and idle tills.** The sync's stock-existence checks kept every page of the product list in memory, and background re-syncs rewrote rows that had not changed.
- **Enter Demo Store works on web when the browser blocks popups.** The demo signed in through the fallback redirect, but the result was never picked up, so nothing opened.
- **iOS: the cart quantity no longer shows the previous value after a quick run of taps.** The order was right; only the field lagged.
- Developers: the native and desktop apps send an `X-WCPOS-Instance` header identifying the installation on every store request, and web sends it once a per-site probe confirms the header passes (plugin 1.11.3 uses it to count integrity drift per till); translations updated to 2026.10.3.
