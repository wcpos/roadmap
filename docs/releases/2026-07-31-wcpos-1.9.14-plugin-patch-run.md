# WCPOS Release Run Reference — 2026-07-31 (1.9.14 plugin-only patch)

A **plugin-only patch** of the free and Pro PHP plugins (no monorepo / web-bundle / electron /
mobile this cycle). Headline: **receipt PDFs fataling on PHP 8.4+ for Pro installs** — the scoper
had namespace-prefixed PHP 8.4's new native `http_*` functions inside vendored Dompdf, the free
plugin shipped shims but Pro's bootstrap never loaded them. Fixed at both ends (Pro loads the
polyfills; free's build stops prefixing the symbols) plus CI guards so the class can't ship again.

## What shipped

- **Receipt PDFs fixed on PHP 8.4+ (Pro)** — every PDF render on a PHP 8.4+ Pro install fataled
  with `Call to undefined function WCPOS\Vendor\http_clear_last_response_headers()`. Pro now loads
  the free plugin's `Vendor_Prefixed_Polyfills.php`
  ([pro #398](https://github.com/wcpos/woocommerce-pos-pro/pull/398)), and free's build no longer
  prefixes PHP 8.4 native symbols at all
  ([free #1417](https://github.com/wcpos/woocommerce-pos/pull/1417)). CI guards: vendor_prefixed
  call audit ([free #1415](https://github.com/wcpos/woocommerce-pos/pull/1415)), 'current' PHP
  matrix group with 8.4 ([free #1416](https://github.com/wcpos/woocommerce-pos/pull/1416),
  [pro #401](https://github.com/wcpos/woocommerce-pos-pro/pull/401)), Pro bootstrap-parity + PDF
  smoke tests ([pro #400](https://github.com/wcpos/woocommerce-pos-pro/pull/400)).
- **Receipt timestamps respect the WP time format** setting
  ([free #1400](https://github.com/wcpos/woocommerce-pos/pull/1400)).
- **Hardened cloud-print job handling** — bulk-cancel restricted to actual print-job post types
  ([free #1401](https://github.com/wcpos/woocommerce-pos/pull/1401)); cancel refused for
  non-waiting jobs so failed jobs stay retryable; atomic status transitions
  ([free #1360](https://github.com/wcpos/woocommerce-pos/pull/1360)).
- **`wp wcpos anon-id` works on Pro-only installs** ([pro #400](https://github.com/wcpos/woocommerce-pos-pro/pull/400)).
- **Updated translations** — `2026.7.8` in both plugins.
