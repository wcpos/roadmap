## Part D — Biggest structural gaps, in priority order

1. **No native acknowledged lane.** `printableLanes: ['raw']` plus a discovered-but-unread `secureTarget` means every phone print to a RED Epson is a quarantine by design — the single largest unbuilt transport.
2. **Signatures are computed and thrown away.** `identity.securePrinting`, `vendorSource`, `notReceiptPrinter` and the per-port states exist; no screen reads them, so the app can classify a printer and still say "check your Wi-Fi".
3. **No "copy setup report" facility.** `buildSupportDetails` (`dialog/test-print-error.tsx`) covers one failed test print. There is no export of identity + port matrix + platform + the last N `printerLogger` lines — the doctrine's "merchants' printers become the test rigs we never buy".
4. **No status query outside ePOS.** BLE offers `DLE EOT` on 2AF0 and USB/serial have read paths; nothing reads them, so paper-out, cover-open and "did it print" are unanswerable on every raw lane.
5. **No `httpStatus` in the identity model.** 503 (held/busy), 404 (ePOS off) and a refusal are one undifferentiated outcome, which blocks three of the four Epson troubleshooting branches.
6. **Two dialogs, two behaviours.** The setup flow got the rulings; the edit dialog still rewrites ports from a name-only vendor, shows "Detected: Epson" with the printer off, and toasts "sent".
7. **No Bluetooth Classic SPP or generic BLE transport on native.** Every clone Bluetooth printer is unsupported on both phone platforms, and the refusal is a developer string.
8. **The connection-error builder is a browser artefact** used on all platforms: three numbered suggestions, certificate advice inside Electron — structurally at odds with "one line + actions + docs link".
9. **Observability stops at the transport boundary.** Main-process handlers log well; renderer adapters (web ePOS, WebPRNT, native SDK) and every markup job do not, so half the lanes have no timeline.
10. **One print queue for all printers**, four different timeouts, no cancel — a hung printer stalls the till rather than one profile.
