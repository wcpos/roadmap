URLs never change: /error-codes/SYNC121 resolves in every variant, because the app's Help link is built from ERROR_CODE_DOCS_BASE_URL. Switch the variant, then switch how the merchant arrives.

Waiting on Paul

  • Pick A, B or C. I recommend B, domain pages. A merchant arrives from the app's Help link or from a search, almost never by browsing.
