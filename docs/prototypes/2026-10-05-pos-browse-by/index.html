Categories, root. The WooCommerce category tree as tiles: image if the category has one, otherwise the name on a tinted card. All products is the first tile, always. The filter bar is untouched in every mode (owner, 2026-10-05).

Tapping Drinks dealt these out of the Drinks tile, which walked to the first slot and is the way back — the same deal as variations. The crumb is the existing component, unchanged. A category set to subcategories shows only the child tiles; one set to products shows only products.
