I think I prefer that." So every option below starts from the stepper chosen on 2026-09-11 (docs/prototypes/2026-09-11-tender-pane-mockups): four nodes on a line, connected · 82% in the card head. What every option changes, before the log itself
  • The stepper is horizontal again, as chosen: done nodes green with a green line behind them, the live node a white disc with a blue ring, the failed node a red cross, a cancelled node a grey minus.
  • A red cross at the ring's size when the leg fails, where the spinner was. The Paid beat has a 96 pt tick; failure gets the same weight, red. A cancel or time-out gets a grey minus at the same size: nobody lost money.
  • Words, not wire. Reader action rdr_20XY…:4297… created on rdr_20XY… becomes Sent to Paul Solo; the ids move to a muted mono line only where the log is open. One message catalogue (bottom of the page) maps every server and client event to cashier copy; unknown messages fall through unchanged.
  • "Declined or cancelled on the terminal" when the provider cannot tell them apart (SumUp reports both as FAILED). "Cancelled on the terminal" after a declined card is wrong copy.
  • One row shape everywhere: level mark · message · time, ids in mono underneath. Same row in the Logs screen, the register closure, the printer log.
